# EasyWork 出海 AI 工作台：三分钟演示脚本

> **v0.3 演示入口已更新（2026-10-31）**：先填写称呼进入演示登录，再从首页四个状态卡和询盘列表打开独立 Tab。新版推荐路径见 [工作空间 v0.3 说明](WORKSPACE_V03.md#建议演示路径)。下文保留 v0.2 的业务话术与原脚本；默认 V1、重新体验、新建即重置和默认画板等入口细节不再适用，请以 v0.3 说明为准。阶段按钮只导航，不自动生成或接受方案。

日期：2026-10-30。适用对象：本地交互 Demo。

## 演示声明

这次展示产品体验与业务闭环：同一个用户在对话和画板中使用多种专业能力。当前 Demo 使用合成商品、预置素材和模拟生成；金额由本地程序计算。没有真实账户权限系统，同一个用户可以完成全部步骤。模型、CLI、MCP 和买家资料查询不代表真实外部调用。

开场时说明一次，页面持续保留演示标识；不要把动画或执行记录称为“已调用真实模型/MCP”。

## 演示前准备

1. 按项目 README 打开 Demo，使用桌面宽屏窗口。
2. 点击“重新体验”，在弹窗点击“重新开始”，回到 V0。主线现场再点击“分析这条询盘”生成 V1。默认预载 V1 仅用于快速查看样例，应明确说明。
3. 确认本次流程所需能力处于启用状态。停用异常留作问答时展示，不占主线时间。
4. 准备三个输入；页面提供“分析这条询盘”“改为300件试单”“接受现货方案”快捷动作，依次覆盖初始生成和两次修改。
5. 确认导出下载权限和本地存储可用。无需模型密钥或网络服务。

## 三个业务输入

**初始询盘：**

> 墨西哥客户要1000个定制帆布袋，希望10天内收到，并询问是否有认证。请分析需求，准备英文和西语回复。

**第一次修改：**

> 客户改成300件试单，希望7天内要用。给我备选方案和报价。

**第二次修改：**

> 客户接受现货无印花方案。运费待确认，写清3天是出库时间，不保证7天到货。

## 备选演示：能力停用和恢复

主线完成后，在能力市场停用“报价计算与导出”，返回工作台点击“把数量改成600件”。页面说明缺少能力，保留原成功版本。重新启用后再执行，现货商品小计更新为 USD 1,080.00。

讲述：“这里的能力不是装饰按钮，执行前会检查依赖。不能调用时会明确说明，避免让用户误以为流程已经完成。”

也可以停用“准备客户资料”，再到资产库点击“整理当前回复材料”或“加入画板”，查看启用提示。它是独立素材步骤，停用不阻断报价；不要将其讲成整个流程执行失败。

## 备选演示：刷新与画板操作

- 拖动一张卡片，缩放画板，再恢复适合视图；业务数量和金额应保持不变。卡片拖动、选择和缩放为真实本地交互，不宣称完整画板引擎已经实现。
- 选中卡片后点击“用选中内容继续”，查看输入区的上下文标签；用标签上的关闭按钮清除已带入内容。画板选择和已带入的上下文是两个操作。
- 刷新浏览器，恢复可用 localStorage 中的案例、版本和画板位置/视图；说明这是当前浏览器和地址下的本地保存，不是服务器同步。
- 打开旧版本，核对它仍保留当时的需求，不被新版覆盖。
- 点击“整理客户回复材料”，在资产库查看按版本保存的草稿。材料不会自动发送，也不会自动成为可信 Wiki 条目。

## 常见问题的准确回答

**“这是真正的 AI 生成吗？”**

当前这份是本地交互原型，生成和外部调用采用模拟，报价计算是本地确定性逻辑。真实模型接入属于后续实现与验收。

**“是不是每个人扮演一个岗位？”**

不是。每个使用者都能调用这些专业能力，同一个人就可以推进当前业务。岗位标签帮助理解能力，不限制人员。

**“MCP 已经连接公司数据了吗？”**

当前 Demo 没有真实 MCP 数据连接。界面展示能力目录、启停、引用与调用反馈的设计。正式接入时应展示真实连接状态、来源和错误处理。

**“能证明询盘转化率提高了吗？”**

本次能展示需求理解、方案准备、资料复用与多轮修改流程。转化率需要真实业务使用和后续数据验证。

**“所有合规问题都能判断吗？”**

当前只演示有限的信息真实性与报价条款检查；没有依据的内容保持待确认，不给全面法律合规结论。

## 演示后的记录

记录观众是否理解以下三点：一人可以完成跨岗位工作；知识和资产被实际引用到产物；客户改变需求后，关联材料同步更新。把找不到入口、看不懂状态、无法判断结果来源等问题记入下一版改进。

不要用预置数量、演示客户反馈或模拟执行日志推导真实订单、生产可用性或商业收益。
