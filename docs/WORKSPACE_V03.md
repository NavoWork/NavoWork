# EasyWork v0.3：业务概览与多询盘工作空间

日期：2026-10-31（Asia/Shanghai）  
适用范围：本地交互原型；本说明更新 v0.2 的入口、页面结构和询盘管理方式。原 PRD 中业务计算与模拟边界继续适用，旧版“默认 V1、单项目、新建即重置、默认画板”描述不再代表当前界面。

## 本次变化

| 原 v0.2 | 当前 v0.3 |
|---|---|
| 直接进入一个询盘 | 演示登录后进入业务概览 |
| 固定一个项目，“新建”打开重置确认 | 可创建独立询盘，多询盘通过 Tab 切换 |
| 首页即对话加无限画板 | 首页显示待办、进行中、待确认、已结束四卡和询盘列表 |
| 画板占据主工作区 | 结构化成果是默认主区，画板通过“查看业务关联”打开 |
| 阶段操作可能触发预置业务步骤 | 阶段按钮只导航；生成和接受方案由明确动作触发 |
| 回复以生成内容展示 | 当前业务版本的英/西语回复可编辑为独立草稿 |

页面延续白灰黑视觉，状态和当前事项使用克制的颜色提示。手机端首页状态卡为两列，询盘页用“对话 / 业务结果”切换主要区域。

## 登录后的业务首页

演示登录仅填写称呼，不要求账号或密码，不提供身份认证。进入后先看到四个状态计数：

- **待办**：尚待开始处理的询盘。
- **进行中**：正在分析、准备方案或整理回复。
- **待确认**：等待客户或资料补充；状态由当前用户管理。
- **已结束**：结束本次工作、保留历史材料。并不表示成交或业务风险已消除。

点击状态卡或列表上方筛选项，显示对应询盘；支持按询盘名称和客户搜索。每条列表展示名称、客户、当前状态及下一步。点击后打开顶部独立 Tab。

初次使用准备四条合成客户示例，均沿用墨西哥帆布袋场景，分别展示四种进度。已有旧版存储会迁入新工作空间。新建询盘填写标题和客户，会建立独立数据，不清空已有工作。

## 询盘内部如何工作

顶部保留“读懂询盘 → 准备方案 → 完成回复”三个可来回切换的阶段。点击阶段只改变当前查看区域，不执行生成，不新增业务版本，不自动接受方案。

左侧对话用于提出需求和修改；右侧默认展示：

- **需求与风险**：采购数量、交期、方案状态、供货依据和待确认事项。
- **方案与报价**：当前版本报价，未知运费、税费与最终总额继续保留待确认。
- **客户回复**：英语和墨西哥西语切换、草稿编辑、复制和材料整理。
- **资料依据**：查看支撑当前结果的资料和来源。

交期冲突在结果区顶部直接显示：定制生产 14 天，不能据此支持客户 10 天到货要求。现货 3 天指付款条件满足后的出库时间，不表示能保证最终到货日期。

画板仍支持原有拖动、选择、缩放与引用功能，入口为“查看业务关联”；通过“返回业务结果”切回固定布局。业务数据与画板共用同一份询盘上下文。

## Tab、状态和保存

- 重复打开同一询盘只激活已有 Tab；关闭 Tab 不删除询盘，可从首页或最近询盘重新打开。
- 各询盘独立保存业务数据、对话、版本、资料引用、回复草稿和相关界面状态。
- 切换询盘可以恢复各自的工作内容；同地址刷新先回到首页，保存的 Tab 和数据仍可继续打开。
- 状态下拉菜单与首页计数关联。已结束询盘保持只读；重新打开后可继续工作。
- 回复草稿按询盘、业务版本和语言保存。新版本重新生成文本，编辑旧版不会替换新版本结果。
- 演示登录和业务数据均保存在当前浏览器；退出登录不等于删除资料。不同称呼不提供账户隔离。

## 建议演示路径

1. 输入称呼进入首页，展示四个状态卡。
2. 点击“待办”，打开未分析的询盘；返回首页，再打开另一条，展示两个独立 Tab。
3. 回到待办询盘，分析 1000 件定制需求，看到交期冲突和双语草稿。
4. 用快捷动作改为 300 件试单，核对现货备选与 `USD 540.00` 商品小计；继续确认方案，保留运输、认证及费用待确认事项。
5. 在“客户回复”切换语言并编辑草稿，查看版本对比，整理和导出材料。
6. 切回另一条询盘，展示其原有内容未被前一条修改覆盖。
7. 手动将一条询盘标记“已结束”，返回首页查看计数变化；重新打开可继续处理。
8. 按需要展示“查看业务关联”，无需将拖动连线作为完成任务的必经步骤。
