# EasyWork 出海工作台 · 0.2 设计更新

日期：2026-10-30（Asia/Shanghai）  
目的：按用户指定的工作台风格调整现有 Demo，让对话、画板和资源导航更接近简洁的桌面客户端。

## 参考与证据

用户指定的参考为[工作台站点](http://118.178.229.75:40002/)。本次读取到了该站公开的 `src/index.css`，HTTP 返回 200；读取到的设计信息支持白灰黑主色、浅灰内嵌区域、细边框、10px 基础圆角，以及浅色半透明侧栏和轻阴影。

浏览器截图多次超时，因此本轮没有依据参考站截图进行逐像素核对，也不声称已看到该站最终渲染界面。CSS 信息是设计输入，不能证明完整页面的布局、动态行为或所有交互细节。

## 本轮采纳的设计

| 内容 | 采纳方式 |
|---|---|
| 白灰黑配色 | 主操作 `#000000`，正文 `#1a1c1e`，内嵌背景 `#f4f4f5`，画布 `#fcfdfe` |
| 轻分隔 | 边框使用 `rgba(31, 34, 37, 0.08)` 至 `rgba(31, 34, 37, 0.10)`，以留白和轻阴影组织层次 |
| 圆角尺度 | 以 `10px` 为基础，按控件用途保留必要变化 |
| 桌面工作台结构 | 左侧资源导航，中间对话，右侧业务画板，顶部使用当前业务标签 |
| 状态表达 | 黑白为界面基调，风险保留提示色、文字与图标；选中、停用和历史状态仍需清楚可见 |

顶部业务标签用于标识当前帆布袋询盘案例，不新增多项目、多会话或浏览器标签管理能力。页面内容与交互仍由本项目独立实现；本轮不复制参考站源代码。

## 保留的业务内容

- 同一个人使用运营、业务、采购、美工、合规能力，无需切换岗位身份。
- 保留工作台、知识 Wiki、资产库、能力市场、版本记录五个入口。
- 保留“分析这条询盘 → 改为300件试单 → 接受现货方案”的两条工作流和三版本主线。
- 保留真实本地金额计算、画板选择/拖动/平移/缩放、localStorage 保存、能力依赖检查、版本回读和 HTML 导出。
- 保留两类业务校验、风险标记和文字批注；未知运费、税费、认证与到货信息继续保持待确认。
- 模型、CLI、MCP 仍为预置流程或模拟记录；视觉更新不构成真实后端接入。
