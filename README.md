# EasyWork 出海工作台 · 交互 Demo v0.3

一个人，在同一个工作空间完成询盘理解、商品核对、报价、资料准备、双语回复与风险检查。运营、业务、采购、美工、合规是可调用的专业能力，不需要切换账号或人员。

**这是零前端依赖的本地交互原型。** 登录为演示入口，客户与商品为合成资料，回复采用预置表达，业务按固定规则执行；尚未接入真实模型、公司数据或账户服务。

v0.3 将入口改为“演示登录 → 业务概览 → 独立询盘 Tab”，询盘内部以业务阶段和结构化结果为主，画板通过“查看业务关联”按需打开。改版范围与体验路径见 [工作空间 v0.3 说明](docs/WORKSPACE_V03.md)。白灰黑视觉沿用 v0.2，历史设计来源见 [设计更新说明](docs/DESIGN_UPDATE.md)。

## 打开方式

在项目目录启动本地静态服务：

```bash
cd /Users/mac/Desktop/SS/easywork-overseas-demo
python3 -m http.server 8767 --bind 127.0.0.1
```

浏览器打开 [本地 Demo](http://127.0.0.1:8767)。终端按 `Ctrl+C` 停止服务。运行页面无需安装 npm 包、配置 API Key 或连接模型服务。

生成可双击打开的单文件版本：

```bash
python3 build.py
```

结果为 `dist/demo.html`，可直接用浏览器打开。修改源码后须重新打包。单文件与本地服务地址的浏览器存储可能相互独立，演示时建议固定一种打开方式。

## 先体验首页和多询盘

1. 首次打开填写称呼，点击“进入演示工作台”。无需账号或密码，称呼只用于本地演示。
2. 登录后默认进入首页，展示 **待办、进行中、待确认、已结束** 四个状态卡和询盘列表。点击卡片筛选对应状态，也可搜索询盘名称或客户。
3. 点击列表中的询盘，在应用顶部打开其独立 Tab。重复点击同一询盘会切回已有 Tab，不重复创建。
4. 返回“工作台”打开另一条询盘，再切回第一条，继续各自的对话、报价、回复和版本。关闭 Tab 仅关闭页面入口，不删除询盘。
5. “新建询盘”填写名称和客户后，创建独立案例并打开 Tab，不重置已有数据。本版新案例仍使用同一帆布袋演示业务规则。
6. 在询盘右上方修改状态，首页计数与筛选随之更新。“已结束”保留材料供查看，需要继续编辑时点击“重新打开询盘”。结束状态不代表成交，也不会自动消除风险。

首次使用会准备四条不同进度的演示询盘。待办案例从未分析状态开始；其他案例用于展示进行中、待确认和已结束视图。若当前地址存在旧版案例，将优先迁入新工作空间，不要求清空原数据。

同一浏览器、同一页面地址下，刷新会回到业务概览，已打开的询盘 Tab 和各询盘数据从本地存储恢复。退出演示登录不会删除询盘；清理浏览器站点数据则可能丢失本地记录。

## 再体验一条询盘的业务主线

从首页打开未分析的待办询盘，或新建一条演示询盘：

1. **分析这条询盘**：客户要 1000 个定制帆布袋，希望 10 天内收到并询问认证。系统指出定制生产需要 14 天、认证证明缺失，并生成英语和墨西哥西语草稿。
2. **改为300件试单**：客户希望 7 天内要用。定制款 MOQ 为 500，系统提出现货无印花备选；商品小计 `300 × USD 1.80 = USD 540.00`，方案仍待客户接受。
3. **接受现货方案**：保留“3 天是满足付款条件后的出库时间，运输与到货待确认”的说明。运费、税费与最终总额仍未知。
4. **核对客户回复**：进入“客户回复”，切换英语或西语，编辑当前版本的回复草稿。修改保存在当前询盘、当前版本中；新业务版本会重新生成文本。
5. **整理客户回复材料**：保存为当前询盘的资产草稿；点击“导出材料”下载所选版本的 HTML 报告，包含报价、双语回复、核对清单、风险与来源。

首次分析和两次修改形成 V1、V2、V3。阶段按钮“读懂询盘 / 准备方案 / 完成回复”只切换正在查看的业务区域，不会自动执行生成、创建新版本或替客户接受方案。业务操作通过明确的快捷动作或对话输入触发。

原三分钟脚本保留在 [演示脚本](docs/DEMO_SCRIPT.md)，其中 v0.2 的入口与画板操作以 [v0.3 说明](docs/WORKSPACE_V03.md) 为准。

## 当前可以操作什么

| 页面或区域 | 可操作内容 |
|---|---|
| 演示登录 | 输入称呼、进入工作台、退出演示会话；不进行真实身份认证 |
| 工作台首页 | 四个状态计数与筛选、客户/询盘搜索、新建和打开询盘 |
| 询盘 Tab | 多页切换、独立保存数据、关闭标签后重新打开 |
| 业务阶段与结果 | 需求/风险、方案/报价、可编辑双语回复、资料依据；阶段只导航 |
| 对话 | 固定范围内的业务指令、方案修改、能力依赖和失败反馈 |
| 业务关联 | 六类关联卡片、选择引用、拖动、平移、缩放与适应画布 |
| 知识 Wiki | 搜索五个演示条目，查看正文、来源与版本，关联当前询盘 |
| 资产库 | 搜索与预览示意素材，检查 SKU 后关联，保存当前询盘的材料草稿，下载资料 |
| 能力市场 | 按 Skill / CLI / MCP 筛选七项能力，查看输入输出、启停及模拟执行记录 |
| 版本记录 | 查看当前询盘的历史版本与差异，导出所选版本；历史不覆盖最新版本 |

画板不再默认占据主工作区。进入“查看业务关联”后，仍支持卡片拖动、空白平移、点击选择、`Shift`＋点击多选、`Ctrl/⌘`＋滚轮缩放，以及“适应全部卡片”。选中后可通过“用选中内容继续”带入引用，返回结构化结果即可继续核对业务材料。

历史版本和已结束询盘保留只读边界。进入最新版本、重新打开已结束询盘后，才可继续相应修改。

## 真实实现与模拟边界

| 真实执行的本地功能 | 演示数据或模拟部分 |
|---|---|
| 多询盘管理、Tab 切换、状态筛选及本地恢复 | 客户、商品、库存与初始询盘均为合成资料 |
| 整数分算价；检查 MOQ、库存、未知费用和交期口径 | Skill 使用固定规则和预置流程，没有真实模型生成 |
| 版本快照、差异回读、独立回复草稿、能力依赖阻断 | CLI 为模拟记录，浏览器不会启动命令行进程 |
| 画板选择、拖动、平移、缩放与资料引用 | MCP 为模拟记录，没有连接公司或外部服务 |
| HTML 下载、双语回复复制、本地 SVG 示意资料 | 双语文本是模板表达；图片不是 AI 商品摄影 |

本版未实现真实平台登录、用户隔离、买家背调、知识上传与向量检索、服务端保存、跨设备同步、多人权限、自动发送客户消息、自动发布商品或下单。输入不同称呼不会创建独立账户，同一浏览器地址继续使用同一份演示资料。

本地保存依赖 localStorage。浏览器禁止保存时可能无法恢复，源文件和导出报告不会因此自动同步到服务器。没有真实生产运行指标，不能据此保证后端可用性或询盘转化率提升。

## 输入和异常体验

优先使用页面快捷动作；也支持数量修改、现货方案、明确接受等短句。超范围输入会提示，不创建虚构的成功结果。

- V3 后改为 600 件现货，商品小计更新为 `USD 1,080.00`。
- 现货改为 900 件，超过演示库存 800，返回错误并保留上一成功版本。
- 停用报价必需能力后修改报价，会提示缺少能力；启用后可重试。
- 停用产品资料整理能力后，加入素材或整理材料会要求先启用。
- 给现货方案加入定制款素材，会提示 SKU 不匹配。
- 在供货核对清单标记“已阅读”，只记录阅读状态，不代表业务事实已确认。

商品小计不等于最终交易总额；未知运费和税费不能当作零。缺少认证材料时，不生成“已认证”结论。

| 文件 | 用途 |

| `tests/cases.test.cjs` | 多询盘独立性、Tab 管理和恢复校验测试 |
| `tests/app.test.cjs` | 交互状态、导出、资料与业务阶段回归测试 |

| `build.py` | 将样式和脚本嵌入单文件 Demo |
| `dist/demo.html` | 打包生成的可双击版本 |

| `docs/DEMO_SCRIPT.md` | 原三分钟业务脚本；新版入口见 v0.3 说明 |

运行 Node.js 内置测试：

```bash
node --test tests/*.test.cjs
```

测试命令不代表已通过的验证结果，实际运行记录以 [VALIDATION](docs/VALIDATION.md) 为准。自动化测试不替代浏览器交互验收或真实后端集成测试。演示页面本身无需 Node.js。

运行使用原生 HTML/CSS/JavaScript 和浏览器 API，没有第三方前端运行包、CDN 脚本或外部字体依赖。素材为内嵌 SVG，知识中的外链是参考来源。Python 用于本地服务与打包，Node.js 用于测试。

下一步工程接入仍包括真实账户、模型及结构化输出、服务端案例版本、受控报价工具，以及真实知识/商品数据连接。当前模拟执行记录不能作为真实外部服务调用证据。
