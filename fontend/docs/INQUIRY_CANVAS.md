# 询盘资料画板

询盘工作区左侧用目录与无限画板汇总当前询盘数据，右侧默认显示 AI 对话，可切换查看业务结果。使用 MIT 许可的 React Flow 12.12.0，复用其拖拽、平移、缩放、节点选择、连线、适应视图及小地图能力。

## 操作

- AI 对话、运行进度和输入框集中在右侧，左侧画板与资料标签使用完整高度。手机可在「画板与资料」和「AI 助手」之间切换。
- 目录与画板、画板与 AI 面板之间均可拖拽调宽，悬停时显示高亮。宽度按当前用户、工作空间和询盘在本机记忆，刷新或收起再展开后保留。
- 目录缩到最小宽度后，继续向左拖超过 40px 会自动收起文件夹列表，画板随之扩展。点击左上角目录按钮重新展开，恢复这次拖拽开始前的宽度；仅调整到最小宽度不会收起。
- 双击分隔线恢复默认宽度；聚焦分隔线后，左右方向键微调 16px，按住 Shift 调整 40px，Home/End 到达最小/最大宽度，Enter 恢复默认。目录范围 140–360px，AI 面板范围 280–720px，空间不足时自动缩小可调上限，为资料区和画板保留空间。手机使用面板切换与目录抽屉。
- 画板默认打开。单击节点选择，双击打开对应资料标签页。画板卡片只显示预览。
- 目录按客户询盘、需求与方案、客户回复、资料与附件、工作笔记、版本记录归档。单击资料定位画板节点，双击或按 Enter 打开标签页。
- 同一资料只打开一个标签。标签支持关闭、切换和方向键导航；关闭不删除资料，画板始终保留。
- 顶部加号可以新建笔记、文件夹或导入文件。笔记可命名、编辑、移动到文件夹及导出 Markdown。
- 本机导入图片、PDF 和文本可在节点及标签中预览；文本预览上限 200 KB，其他格式可下载原文件。单文件上限 20 MB。
- 拖拽节点、移动视口及缩放后自动保留位置；「整理画板」恢复默认排列并适应全部节点。

## 标签类型与保存

| 类型           | 内容与编辑方式                                                   | 保存位置                                           |
| -------------- | ---------------------------------------------------------------- | -------------------------------------------------- |
| 客户原始询盘   | 首次处理前可修改并保存；首次处理后原文留档，补充内容在沟通页提交 | 现有询盘 PATCH 接口，保留元信息版本校验            |
| 沟通与处理记录 | 左侧标签回看沟通留档；右侧 AI 对话显示消息、运行进度与输入框     | 现有消息及 Run 接口                                |
| 客户需求与规格 | 当前版本预览，可编辑为工作草稿并交给助手核对                     | 本机工作草稿；提交处理后由 Run 生成业务版本        |
| 风险与待确认项 | 当前风险清单及建议，可补充工作草稿                               | 同上                                               |
| 方案与报价草稿 | SKU、数量、单价、小计、运费、税费、差异说明                      | 同上；手工文本不直接改变报价快照                   |
| 双语回复草稿   | 英语、西语独立编辑、自动保存、冲突比较和重新复核                 | 现有回复草稿接口                                   |
| 引用资料       | 当前业务版本引用的固定来源全文，可添加询盘备注                   | 来源只读；备注存于本机                             |
| 附件           | 图片/PDF 预览、原文件下载，可修改当前询盘中的显示名称            | 已引用文件沿用素材接口；本机导入文件使用 IndexedDB |
| 工作笔记       | 自由文本、标题、所在文件夹、Markdown 导出                        | 本机自动保存                                       |
| 版本快照       | 变更摘要、保存时间，可打开对应业务版本                           | 现有业务版本接口，只读                             |
| 材料草稿       | 版本、双语草稿版本、来源及附件清单                               | 现有材料草稿接口，只读                             |

## 数据边界

画板本机数据以用户、工作空间和询盘 ID 组成独立存储键。布局、标签、工作草稿、笔记及自建文件夹使用 localStorage；导入文件内容使用 IndexedDB。当前实现不包含跨设备或团队同步。本机附件不会自动成为报价 Run 的正式引用素材，正式引用继续通过右侧「选择引用素材」提交校验。

历史版本、等待确认、结束和运行中的业务内容沿用现有只读规则。业务快照不会因修改本机工作草稿而改变。原文、回复保存失败时保留输入并显示错误；本机存储异常也会明确提示。示例素材只有元信息、缺少文件内容时，显示接口返回的说明。

## 实现位置

- `InquiryCanvas.tsx`：React Flow、目录、标签页与询盘内资料聚合。
- `InquiryDocument.tsx`：原文编辑、生成内容工作草稿及文件预览。
- `inquiry-canvas-model.ts`：资料映射、本机状态及附件存储。
- `InquiryWorkspace.tsx`：左右布局、AI 对话与业务结果切换，接入现有业务流程、回复保存和版本切换。
- `components/ResizeHandle.tsx`：两条边界共用的指针拖拽、键盘调宽及宽度边界处理。
- `tests/e2e/inquiry-canvas.spec.ts`：节点与标签、编辑回显、原文保存、询盘隔离、文件恢复、拖拽、面板调宽与恢复、主题及移动布局回归。
