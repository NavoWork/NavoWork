## 本轮修复

- 请求搜索/分页使用独立 Query key 和请求取消，旧响应不覆盖新筛选。
- 取消组件卸载时的自动网络写入，避免重新登录另一账号后提交旧账号草稿；保留隔离的未同步恢复副本。
- 草稿状态绑定业务版本，防止刚切版本时使用上一版本的草稿号导出。
- 历史视图不混入本机未保存修改；保存失败不标成功。
- Tab 偏好写入容忍浏览器禁用/配额异常；异常 URL 显示可理解错误。
- 直接链接加载失败的重试重新触发该询盘请求。
- 新建提交期间锁住输入，避免提交后的新增文字被成功关窗丢弃。
- 知识列表和编辑器使用资料 ID 与版本联合标识；发布后保留历史版本。

## 尚未验收 / 联调边界

1. 真实账号会话、跨工作空间资源授权、真实文件存储、后端进程重启恢复和跨设备读取，需要 B/C 服务。
2. 任意新询盘的真实模型理解、正式确定性报价、业务语义审校及英西语言质量，需要 B/C/D；Mock 固定案例通过不代表这些能力已上线。
3. API 文档未明确的响应包、认证请求及素材固定版本表示已记录在 INTEGRATION.md，需后端共同冻结。
4. 本次使用契约允许的运行状态轮询；SSE 事件去重/重连适配未实施，不能声称 SSE 验收通过。
5. 初始素材元信息没有附带真实文件，预览会明确报错；用户上传测试图片后的预览下载已验证。
6. 发布新资源后的全量依赖更新提示、完善的能力运行审计视图、资源撤销入口与外部服务行为尚待后续联调；当前展示已有来源版本与询盘运行摘要。
