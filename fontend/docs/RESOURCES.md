# Navowork 知识库与资产库

更新日期：2026-11-01

## 当前页面

知识库与资产库在 real 模式使用真实服务，在 mock 模式使用示例内容。知识库页面和 @ 选择器通过 `wiki-store.ts` 共享缓存：real 模式读取 `/library/documents`，mock 模式按用户和工作空间保存在本机。页面在 `StaticLibrary.tsx`，请求适配在 `library-api.ts`。

| 页面                | 内容                                                                                          | 交互                                                                              |
| ------------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `/knowledge` 知识库 | Mock 初始 8 篇 Markdown 文档；业务流程、产品资料、客户沟通、团队协作四个目录                            | 目录筛选、标题与正文搜索、收藏、排序、阅读与原文切换、正文目录跳转、下载 Markdown |

导航统一使用“知识库”。移除了旧页面的英文标语、发布版本说明、重复的权限页脚与侧栏演示说明，保留文件名称、分类、日期和大小等有用信息。

## real 模式对接

知识库使用 `/library/documents`，资产库使用 `/library/assets`，收藏使用各对象的 `/favorite`。real 模式没有默认静态资料，创建、导入和收藏刷新后保留。个人资产由服务端所有者权限隔离，公司资产由工作空间共享；下载复用带权限检查的素材版本接口。文件最大 100 MB，Markdown 正文最大 2 MB。技能市场通过 `/skill-market` 展示服务端实际能力与规划状态。具体契约及与 Agent 引用的关系见 [适配说明 v1.1](../../doc/Frontend_Backend_Adaptation_v1.1.md)。

个人资产库同时关联询盘资料：真实模式读取服务端画板及附件，Mock 读取本机草稿和 IndexedDB。询盘关联资料的收藏仅保存在当前资产页面；独立上传资产的收藏在 real 模式持久保存。

## mock 模式演示边界

- 知识库新建、导入和收藏保存在当前浏览器；离开页面或刷新后保留，可在询盘中引用。技能与知识调用的范围和后端接入说明见 [INQUIRY_CONTEXT.md](./INQUIRY_CONTEXT.md)。资产库添加文件与收藏仍属于页面内存中的演示。
- 公司与个人空间是静态分类演示，尚未接入真实成员权限、企业数据或个人云存储。
- 初始资产使用本地绘制的示例封面；视频展示封面，表格展示静态内容，示例文件不提供虚构下载。
- 导入 Markdown 支持 `.md`、`.markdown`，单文件最大 2 MB。阅读视图支持标题、列表、表格、引用、粗体、行内代码和代码块；原文视图保留完整文本，不执行嵌入 HTML。
- 添加资产支持任意文件扩展名，单文件最大 100 MB。图片、视频、音频和 PDF 使用浏览器能力预览；其他格式可下载原文件。实际媒体支持取决于浏览器。
- 临时 Blob URL 在离开资产页面后释放。静态页面不改写已有询盘、商品和后端资源数据。
- 旧的 `Resources.tsx` 和已有 API 实现保留在代码库中，当前知识库与资产库入口已不再加载它们。技能市场由独立页面实现。
