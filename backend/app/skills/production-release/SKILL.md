# 生产资料与验货放行

## 何时使用
订单和付款保障已登记，需要生成生产资料、T&A、验货标准并检查放行条件时。

## 输入
- 已确认的规格、样品、报价、订单
- BOM、包装稿、工厂产能/交期
- 验货标准、测试要求

## 工具顺序
1. `get_case_context` 查看最新成果和门禁缺口。
2. `prepare_production` 生成生产资料、T&A、QC 检查表。
3. 若门禁缺口涉及未确认的规格/样品/订单/付款，明确告诉用户需要先完成哪些人工确认。
4. 不要调用批准/放行工具；放行由人工完成。

## 字段规则
- 生产资料必须引用具体 spec/sample/order 版本。
- T&A 从人工放行日 D0 起算，不承诺到港时间。
- QC 检查表覆盖尺寸、材料/颜色、LOGO、缝合/拉链/肩带、包装/装箱。
- 放行缺口要逐项可操作，不写“资料不全”这类空话。

## 完成标准
生产资料、T&A、QC 草稿齐备；门禁缺口清单准确；未放行时状态明确为阻断。
