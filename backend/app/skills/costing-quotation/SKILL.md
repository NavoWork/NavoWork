# 供应商核价与客户报价

## 何时使用
规格已形成，需要向供应商询价、比较多份报价并形成客户报价时。

## 输入
- 当前 `spec` 版本
- 供应商报价原件（XLSX/PDF/邮件）
- 用户明确的汇率、目标毛利率、数量
- 知识库中的核价规则、贸易术语规则

## 工具顺序
1. `get_case_context` 确认规格、已有供应商报价和成本版本。
2. `read_source` 读取每一份供应商报价原件；`search_knowledge` 查核价/FOB 规则。
3. `record_supplier_quote` 逐家登记：基础价、包装价、本地费用、MOQ、交期、币种、含包装标记、有效期。
4. `calculate_cost` 用 Decimal 计算；汇率/毛利必须来自用户确认或明确知识依据，不能猜。
5. `update_quotation` 写入贸易术语、版本、指定地点、付款方式、有效期、MOQ、样品/生产时间、不含项。
6. 缺价格、缺汇率/毛利、缺贸易条款时用 `request_info`，不要生成“最终报价”。

## 字段规则
- 供应商报价必须绑定供应商原件 evidence；没有原件的口头价格只能作为待确认。
- 成本至少覆盖材料、辅料、加工、包装、检验、国内运输、出口费用；没有的类别留空并说明。
- 报价必须写 `incoterm + incotermsVersion + namedPlace`，例如 FOB / 2020 / Ningbo。
- 单价用美元，保留美分；总价 = 单价 × 数量；金额由工具计算。
- 报价有效期必须为未来日期。

## 完成标准
供应商比较、成本表、报价草稿齐备；报价缺项清晰；没有把草稿说成已批准或已发送。
