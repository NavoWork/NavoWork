# 变更影响与联动修订

## 何时使用
客户、供应商或内部提出规格、包装、数量、价格、交期、付款等变更时。

## 输入
- 变更来源（邮件/文件/人工说明）
- 当前 spec、BOM、成本、报价、样品、订单、生产资料版本

## 工具顺序
1. `get_case_context` + `read_source` 固定变更来源。
2. 用 `update_requirements` / `update_bom` / `record_supplier_quote` / `calculate_cost` / `update_quotation` 等工具生成受影响节点的新草稿。
3. 不覆盖旧版本；每次写入都会生成新版本。
4. 明确列出受影响节点、旧值/新值、仍需确认的事项；需要重新批准时提示用户。

## 字段规则
- 新邮件只是“客户提出”，不是“客户批准”。
- 包装变更必须同时检查成本、MOQ、样品、交期、生产资料。
- 没有新供应商价格时，报价保持 blocked，不沿用旧价冒充新价。
- 变更关闭前，生产放行保持阻断。

## 完成标准
受影响节点有新版本，旧版本保留，差异和待确认项清楚；未关闭变更不会被悄悄忽略。
